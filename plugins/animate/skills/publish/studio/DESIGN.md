# Studio design

Preserve the imported dark interface: Barlow type, solid surfaces, 1px borders, and 4–8px corner radii. The original `Flap` and `steel` names remain internal identifiers; the interface uses ordinary text and flat panels.

Amber identifies selected actions, active navigation, schedules and progress. Red identifies errors; green identifies completion. Pair status color with words. Background: `#0d0d0f`; raised panels: `#1b1b1e`; borders: `#2e2f35`; primary text: `#f2f2f2`; secondary text: `#b9bcc2`; subdued text: `#8a8f98`; amber: `#ffb400`.

Keep the episode preview beside editing/publishing controls on large screens and stack them on narrow screens. Wide tables scroll within their containers. The sidebar links Publishing, Channels and Performance. Keys 1–3 switch screens; Escape returns from an episode. Fields have labels, controls keep visible keyboard focus, and motion respects reduced-motion preferences.

Name destinations and accounts explicitly. Separate hard requirements from creative advice. Label X metrics as impressions. Errors should give the next corrective action. Preserve contributor attribution and licensing when changing the design.
